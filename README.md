# Platformer Game (p5.js)

A side-scrolling platformer built from scratch in JavaScript with p5.js.

**Play it live:** https://chizimuzo.github.io/p5-platformer/

## Features
- Floating platforms to jump between and coins to collect, with sound effects
- Patrolling robot enemies that cost a life on contact (5 lives)
- Canyons to avoid, with game-over and level-complete screens
- Animated finish flag that raises when you reach the end
- Press R or click to restart

## Controls
Arrow keys to move and jump.

## Built with
JavaScript, p5.js, p5.sound
